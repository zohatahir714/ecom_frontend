# MERN E-Commerce App 

# ecom_frontend

## Overview
This is the **frontend** of a MERN e-commerce application.  
It provides a responsive user interface for browsing products, managing a shopping cart, and handling user authentication.

## Features
- Product listings with details
- User registration & login
- Shopping cart functionality
- Responsive UI built with React

## Tech Stack
- React.js
- HTML, CSS, JavaScript
- Axios (for API calls)

## Setup Instructions
1. Clone the repo:
   ```bash
   git clone https://github.com/zohatahir714/ecom-frontend.git
2. Navigate to the project folder:
   ...bash
   cd ecom-frontend
3. Install dependencies:
   ...bash
   npm install
4. Run the development server:
   ...bash
   npm start
